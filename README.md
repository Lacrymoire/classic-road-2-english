# Classic Road 2 - English Translation

An unofficial English fan translation of **Classic Road 2** (クラシックロード２), the 1999 PlayStation horse racing and breeding simulation by Victor Interactive Software (SLPS-02039).

## Download
Get the latest patch from the [Releases](../../releases) page. The download contains only a patch file and a readme, with no game data. You need your own copy of the original Japanese disc.

## What is translated
- All menus, messages, dialogue, the secretary's comments, memos, help text, race commentary, news and race previews
- Horse, race, jockey and trainer names
- Pictures with lettering: race name plates, course cards, betting cards, record headers, icons and tags
- Opening movie: English subtitles under the Japanese captions

## How to apply
The patch changes only `Classic Road 2 (Japan) (Track 1).bin` (CRC32 `CAD85145` before patching, `2AACEDD4` after). Apply it with [ROM Patcher JS](https://www.marcrobledo.com/RomPatcher.js/), Delta Patcher or xdelta3. Full instructions are in the README.txt inside the download.

## Reporting problems
Please open an [Issue](../../issues) with a screenshot and a short description of where in the game it happened.
